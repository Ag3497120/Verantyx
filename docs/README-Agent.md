# ⚡ Verantyx Agent (Spotlight Mode)

## The Hyper-Autonomous Local Agent via Dual-Twin & L3.5 Memory

「最強のローカルAIを、脳の拡張として完全に使いこなしたい」というローカルAIハッカー、最先端の自律エージェントを試したい層向けのモードです。
バックグラウンド常駐からの `Control` キー × 3 によるSpotlight風UIの呼び出しで、いつでも瞬時に起動します。

---

## 🚀 主な機能とアーキテクチャ

### 1. Dual Twin による内部監査機構
コードの生成と検証を分離し、2つのAI（Twin）が互いの出力を監査する仕組みです。これにより、単一のLLMでは防げない論理エラーや文脈の破綻を検知・修正します。

### 2. 1930年の Blind Commander メタファ (talkie-1930)
1930年代の「盲目の司令官」というメタファを用いることで、ハルシネーション（幻覚）を物理的に遮断します。この司令官は現代のプログラミング言語を知らない設定になっており、純粋な論理と指示の組み立てに特化しています。これにより、モデルが不確かな知識（プログラミングの構文など）をでっち上げるのを防ぎます。

### 3. L3.5 Memory (Tri-Layer JCross Memory)
PC内の資産を「自分の記憶」として認識する次世代の思考エンジンです。
- **短期記憶**: 直近の会話や作業コンテキスト
- **中期記憶**: 現在のプロジェクトの構造やJCrossのパズル状態
- **長期記憶**: PC全体に散らばる知識ベース、過去の成功パターン

### 4. 漢字トポロジーと空間認識
デコイ（おとり）として機能する漢字トポロジーを活用し、コード構造を空間的に認識します。これにより、AIはファイルやディレクトリの境界を越えて、プロジェクト全体を立体的なグラフとして理解することができます。

### 5. OSネイティブ操作
macOSのAPIを直接叩き、ファイル操作、コマンド実行、ウィンドウ管理などを人間と同じように実行します。SpotlightのようなUIから呼び出されるため、作業の文脈を途切れさせることなくシームレスにAIと連携できます。

---

## 💻 使い方

1. Verantyxを起動し、バックグラウンドに常駐させます。
2. 任意の画面で `Control` キーを素早く3回連続で押します。
3. Spotlight風の入力ウィンドウが表示されます。
4. 自然言語でタスクを指示します。
5. Agentが背後で必要な情報を集め、思考プロセス（`<think>`タグ）を経て自律的にタスクを実行します。
