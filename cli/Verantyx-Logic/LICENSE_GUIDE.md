Verantyx is designed to be edited, restructured, replaced, and extended.
- You can freely modify the Python source code.
- You can freely edit, replace, or rebuild the knowledge databases (JSON / JSONL).
- You can swap domains, add new reasoning systems, or remove existing ones.

**Breaking it, rewriting it, or turning it into something completely different is explicitly welcome.**

---

### Philosophy Behind This License Choice

Most systems hide their intelligence inside opaque model weights. Verantyx does the opposite.

By choosing the MIT License, this project intentionally allows:
- Radical experimentation
- Unconventional reuse
- Domain-specific adaptations
- Commercial and non-commercial evolution

The goal is not to control usage, but to **maximize structural freedom and reproducibility**.

If Verantyx inspires you to build something new, then it is already succeeding.

### このライセンスを選んだ理由

多くのシステムは、知識や推論をブラックボックスの「重み」に閉じ込めます。Verantyx は、その逆を選びました。

MIT ライセンスを採用した理由は：
- 実験を止めないため
- 再現性を最大化するため
- 分野横断的な再利用を可能にするため
- 商用・非商用の壁を作らないため

使い方を制御することではなく、**構造の自由度を最大化すること**が目的です。

Verantyx を土台にして、まったく別のものが生まれるなら、それはこのプロジェクトの成功です。
