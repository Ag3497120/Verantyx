知らないことを、知らないと言える開発環境

The IDE that can say it does not know

Verantyx IDE には決定論的な知識エンジン Vera-α が入っています。 答えられないとき、それらしい文章を作らず、なぜ答えられないかを型で返します。 LLM は一切使いません。同じ入力からは必ず同じ答えが出ます。

Verantyx IDE ships Vera-α, a deterministic knowledge engine. When it cannot answer it does not produce plausible prose — it returns why it cannot, as a type. No LLM anywhere. The same input always gives the same answer.

ハルシネーションを「減らす」のではなく、構造的に起こせなくする

Not fewer hallucinations — structurally none

LLM は分布から次の語を選ぶので、知識が無くても文は出ます。 Vera-α は文を作りません。保存された事実から答えるか、拒否するかのどちらかです。

An LLM picks the next token from a distribution, so text appears whether or not the knowledge does. Vera-α does not generate. It either answers from stored facts, or refuses.

> 避難所 🚫 UNKNOWN_NO_EVIDENCE no_candidate_cross 単体 Vera-a は知らないことを推測しません。文書を投入するか、jgen 合議モードに切り替えてください。Vera-a standalone does not guess. Pour documents in, or switch to jgen council mode.

実際の出力です。空のストアに聞くと、作り話ではなく型付きの拒否が返ります。

Real output. Asked against an empty store, it returns a typed refusal rather than an invention.

型付き拒否

Typed refusal

UNKNOWN_NO_EVIDENCE / UNKNOWN_NO_CAUSE_RECORDED など、 「何が足りないか」が名前になります。次の一手が決まります。

UNKNOWN_NO_EVIDENCE, UNKNOWN_NO_CAUSE_RECORDED — the missing thing becomes the name, so the next step is decided.

出典まで遡れる

Traceable to the sentence

すべての主張は、元の文書の元の文まで戻れます。要約ではなく原文が返ります。

Every claim walks back to the sentence in the source document — the original, not a paraphrase.

完全な再現性

Fully reproducible

同じ文書群からは、バイト単位で同じ結果が出ます。コーパスのハッシュが結論に紐づきます。

The same documents produce byte-identical output. A corpus hash ties the inputs to the conclusion.

矛盾が消えない

Disagreement survives

複数の資料が食い違うとき、要約せずに両方を出典付きで並べます。

When sources conflict it does not blend them — it shows both sides with their sources.

2つのエンジンを、ヘッダで切り替える

Two engines, switched in the header

答えの性格が変わるので、設定の奥ではなくヘッダに置いています。 いま読んでいる答えがどちらのものかは、常に見えているべきです。

The two produce different kinds of answer, so the switch sits in the header rather than deep in settings: which kind you are reading should never be something you go and check.

拒否を LLM に言い直させることは意図的にしていません。 言い直した瞬間、その答えは再現も引用もできなくなるからです。

A refusal is deliberately never rewritten by a model: the moment it is, the answer stops being reproducible and citable — which was the entire point.

災害時の状況板 — 「今、確実に何が分かっているか」

The disaster board — what is certain right now

状態は選ぶものにしています。住民が実際に書く 「ここ給水やってる」のような文は、解析すると10件中0件しか状態を取り出せませんでした。 選択式なら解析が要らなくなります。誰であるかではなく、何が必要かで選びます。

Statuses are chosen, not written. Ten realistic resident postings yielded a usable state in zero of ten when parsed, so choosing removes the parse instead of climbing it. You pick what you need, never who you are.

いま必要なものを選んでください
What do you need right now?

EXPIRED は「閉まっている」ではありません。 「その情報が古すぎて、責任を持って言えない」という意味です。3日前の「給水やってた」が 残っていると人は歩いてしまうので、鮮度切れを検出結果として出します。 鮮度の基準は種類ごとに違います(給水90分、避難所24時間)。

EXPIRED does not mean closed. It means nothing recent enough to stand behind. A three-day-old "water was flowing" sends someone walking, so staleness is a finding. The window differs by category — 90 minutes for a water queue, 24 hours for whether a shelter exists.

公式発表も一つの側であって、答えではありません。市の掲示が「営業」で、 現地の人が「終了」なら、それは見せるべき食い違いです。多数決もしません — 一人だけ違うことを言う人が、その後に行った唯一の人かもしれないからです。 そして信頼度の数値は出しません。数字は根拠のない精密さを演出し、 読み手はそれを許可として受け取るからです。

An official notice is one side, not the answer — and there is no majority vote, because the lone dissenter may be the only person who has been since. No confidence score, either: a number performs a precision nobody has, and a reader takes it as permission.

被災地支援での使い方

Use in disaster response

複数の発表が食い違うとき、要約は食い違いを溶かします。 それは現場の人が最も必要としている情報です。

When announcements conflict, a summary dissolves the conflict — which is exactly the information a responder needs most.

🔄 更新UPDATED 現在は 通行可能（架空放送・15:00 時点Broadcast B, as of 15:00） それ以前: 通行止（架空新聞・09:00）Earlier: closed (Paper A, 09:00) 🔴 係争CONTESTED 避難所は 開設（架空新聞） 対 閉鎖（架空放送） この点は未確定ですThis point is unresolved

時刻が順序づくものは「更新」、順序づかないものは「係争」。 日時が読めないときは安全側に倒し、係争のまま残します。

Ordered in time becomes an update; unordered stays a dispute. An unreadable date fails safe — it can only leave a dispute standing, never invent an update.

オフラインで動き、電源の不安定な場所の安価なノート PC でも数分で終わります。 GPU は不要です — 行列演算を一切しないためです。

It runs offline and finishes in minutes on a cheap laptop where power is unreliable. No GPU needed — there is no matrix arithmetic anywhere in it.
