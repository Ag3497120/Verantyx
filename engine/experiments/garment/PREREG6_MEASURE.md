# 事前登録 — 寸法 (VD1〜VD5)

2026-08-22。縫製師に渡す最後の一段。設計が決まっても、寸法が無ければ
裁てない。

## 映像から採寸はできない

一枚の絵に長さの基準が映っていなければ、袖丈は出ない。「肘下12cm相当」は
観測ではなく**比率の読み**で、基準が入って初めて長さになる。ここを曖昧に
すると、比率から出した数字が実寸の顔をして型紙に乗る。

だからこの装置は寸法を**推定しない**。持つのは三つだけ:

- 実測: 実物・資料から入った長さ (出典と単位が要る)
- 比率: 「着丈の 0.62」のような、基準に掛ける値 (基準が無ければ長さにならない)
- 未取得: まだ無い。**何を測れば埋まるかを添える**

## 測ること

- **VD1 基準の無い比率は長さにならない。** 基準寸法が未取得のまま
  比率だけがある側面は、寸法として出ない。`UNKNOWN_NO_BASIS` と
  その閉じ方が出る。

- **VD2 単位の無い数字を受け取らない。** 単位が空の実測は
  `UNKNOWN_NO_UNIT` で拒む。cm と inch を混ぜた表は裁断を壊す。

- **VD3 基準が入ると比率は長さになる。** 着丈が実測で入った瞬間、
  それに掛かる比率が長さとして計算できる。**計算されたものは実測と
  同じ欄に入らない** — `derived` として別に立つ。

- **VD4 寸法表は欠けを隠さない。** 未取得の寸法は行として残り、
  何を測れば埋まるかが付く。空欄で消えない。

- **VD5 順序不変。** 入れる順を変えても寸法表は同じになる。

反証条件: VD3 で計算値が実測と同じ欄に出たら、この機能は出さない。
比率から出した数字が実寸として型紙に乗る。
