# 事前登録 — 型紙を縫って落とす (VF1〜VF7)

2026-08-23。ここまで、立体・型紙・布シミュが**それぞれ別に寸法から
生えていて、互いを見ていなかった**。立体は寸法から作る塊、型紙は寸法から
引く平面、布シミュは平らな正方形を落とすだけ。どれも動くが、
「この一着がどう落ちるか」にはなっていない。

繋ぐ。**型紙 → 縫い合わせ → 落とす。**

## 縫い目は型紙が決める

どの辺とどの辺を縫うかは、型紙の名前付き辺(`肩線`・`脇線`・`袖ぐり`・
`袖山`)から決まる。**勝手に近い点同士を対応させない** — 近いから縫う、は
型紙を無視して形を作ることになる。

対応が付かない辺は縫わない。縫えない型紙は縫えないと言う(PREREG11 の
検算がそのために先にある)。

## 検証器はそのまま効く

PREREG12 の四つ(順序不変・段の収束・多点始動・同点棄権)は解法に
依存しないので、平らな布から縫った服に替えても同じように効く。

## 測ること

- **VF1 型紙が無ければ縫えない。** 寸法が足りず型紙が引けなければ、
  縫うところまで行かない。
- **VF2 縫い目は名前付き辺から決まる。** 対応表が出力に残り、
  どの辺とどの辺を縫ったかが読める。近さで勝手に繋がない。
- **VF3 出身が残る。** 縫った後も、各頂点がどのピース由来かが分かる。
  混ざると、直すときにどの型紙を触ればよいか分からなくなる。
- **VF4 縫い目が縮む。** 反復のあいだに、縫い合わせた点同士の距離が
  下がる。下がらなければ縫えていない。
- **VF5 検証器が効く。** 順序不変・多点始動が、縫った服でも測れる。
  落ちれば形を返さない。
- **VF6 決定的。** 同じ型紙・同じ順序から同じ座標。
- **VF7 生成物。** 落とした服から `garment_observe` はできない。

反証: VF2 が崩れたら出さない。型紙を無視して近さで縫った形は、
その型紙の服ではない。

## 追記 2026-08-23 — UI に繋いだら、三つの欠陥が出た

画面から呼べるようにしたところ、縫い目が **6.04cm 開いたまま
「閉じた」と報告されていた**。原因を潰した順に書く。

### 1. 「縮んだ」を「閉じた」と呼んでいた

`closed` は `gaps[-1] < gaps[0]`、つまり**縮んだかどうか**だった。
22cm が 6cm になれば合格になる。6cm 開いた縫い目は縫えていない。

許容は選ばずメッシュから出す。目は各ピースの最寄り格子点に付くので、
`cell/2` は原理的な下限。`decreased` と `closed` を別々に返す。

### 2. 袖山を前身頃の袖ぐりだけに縫っていた

型紙側の検算は最初から `袖/袖山` を **前後の袖ぐりの合計** と
比べていた(32.04 対 30.05)。縫う側の `SEAMS` は前身頃だけを見ていて、
袖山の半分が何にも付かないまま袖ぐりに引き寄せられていた。

`SEAMS` に `span`(辺を刻む範囲と向き)を足し、袖山を前半・後半に
分けた。向きは端点で決まる — 袖ぐりは肩から脇へ走り、袖山は脇から
肩を通ってもう一方の脇へ走るので、前半は逆に刻む。

**実測: 反復を 32 倍(200→6400)にしても隙間は 6.06→5.96cm。**
反復では消えない欠陥だった。

### 3. 吊った点に目が乗っていた

最大の隙間がちょうど 24.000cm — 前身頃と後身頃の初期間隔そのもの。
前と後ろを**別々に**吊っていたので、肩の縫い目は動けない点どうしを
結んでいた。吊った点は動けないので、そこに乗った目は原理的に閉じない。

吊るのは前身頃だけにした。後ろは肩の縫い目を通してぶら下がる —
服はそう吊れている。吊り点は縫っていない点から選ぶ。

一点で吊ると回るので、上から帯を広げて左右に離れた二点を取る。

### 4. 目の数が固定 7 本で、同じ格子点に潰れていた

28 本の目が 19 対に潰れ、袖山の 7 本が**頂点 1 つ**に乗っていた。
一つの点は一箇所にしか居られないので、潰れた分は必ず開いたまま残る。
目の数を辺の長さと `cell` から出すようにした(22 本、すべて相異なる)。

### 結果

隙間 **6.04 → 0.79cm**(許容 3.0 = cell/2)。`closed` が本当になった。

## 追加で測ること

- **VF8(測り直し) 多点始動の食い違いは反復では消えない。**
  前の版は 22cm で横ばいだったが、その数字は上の三つの欠陥の上で
  出たもの。直した後は **5.9 → 12.6cm と、反復を増やすほど広がる。**
  「もっと回せばよい」はどちらにしても答えにならない。
- **VF9 食い違いは「揺れ」ではなく「別の形」。** 座標の差だけでは
  区別が付かない。同じ形が吊り点まわりに振れただけなら、**形の中の
  距離**は変わらないはず。実測では中の距離まで 9.5cm 動いていて、
  三枚とも動いている。別の畳まれ方に落ちている。
- **VF10 吊った点には目を付けない。** 吊り点と縫い目の交わりは空。
  吊るのは前身頃だけ。

## ここで止まる — 分かった壁

**吊り下げただけの服は、形が一つに決まらない。** 三つの欠陥を潰した
後も残った。二点で吊った服は、その線のまわりに落ち方が何通りもあり、
重力はそのうちの一つを選ばない。初期配置が選んでいる。

これは解き方の粗さではなく、**問いの立て方**の問題。服の形を決めて
いるのは、実際には中に入っている身体。

だから返さない。落ちた検査を緩めるのではなく、**三つの形を全部返す**。
一つ選べば、初期配置が決めた皺を物理として見せることになる。

次は身体に着せる(利用者が先に頼んでいた「人体モックに着せる」)。
それが入るまで、この一着の落ち方は **UNKNOWN_LOCAL_MINIMUM**。
