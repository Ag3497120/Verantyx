# 事前登録 — 型紙を縫って落とす (VF1〜VF7)

2026-08-23。ここまで、立体・型紙・布シミュが**それぞれ別に寸法から
生えていて、互いを見ていなかった**。立体は寸法から作る塊、型紙は寸法から
引く平面、布シミュは平らな正方形を落とすだけ。どれも動くが、
「この一着がどう落ちるか」にはなっていない。

繋ぐ。**型紙 → 縫い合わせ → 落とす。**

## 縫い目は型紙が決める

どの辺とどの辺を縫うかは、型紙の名前付き辺(`肩線`・`脇線`・`袖ぐり`・
`袖山`)から決まる。**勝手に近い点同士を対応させない** — 近いから縫う、は
型紙を無視して形を作ることになる。

対応が付かない辺は縫わない。縫えない型紙は縫えないと言う(PREREG11 の
検算がそのために先にある)。

## 検証器はそのまま効く

PREREG12 の四つ(順序不変・段の収束・多点始動・同点棄権)は解法に
依存しないので、平らな布から縫った服に替えても同じように効く。

## 測ること

- **VF1 型紙が無ければ縫えない。** 寸法が足りず型紙が引けなければ、
  縫うところまで行かない。
- **VF2 縫い目は名前付き辺から決まる。** 対応表が出力に残り、
  どの辺とどの辺を縫ったかが読める。近さで勝手に繋がない。
- **VF3 出身が残る。** 縫った後も、各頂点がどのピース由来かが分かる。
  混ざると、直すときにどの型紙を触ればよいか分からなくなる。
- **VF4 縫い目が縮む。** 反復のあいだに、縫い合わせた点同士の距離が
  下がる。下がらなければ縫えていない。
- **VF5 検証器が効く。** 順序不変・多点始動が、縫った服でも測れる。
  落ちれば形を返さない。
- **VF6 決定的。** 同じ型紙・同じ順序から同じ座標。
- **VF7 生成物。** 落とした服から `garment_observe` はできない。

反証: VF2 が崩れたら出さない。型紙を無視して近さで縫った形は、
その型紙の服ではない。
