# 事前登録 — 基準体・ゆとり・サイズ展開 (VB1〜VB8)

2026-08-23。立体(PREREG8)の次。**着せない。比べる。**

## 「着せてみる」をやらない理由

本当の着装は、型紙を裁って縫い、生地の重さと曲げ剛性で落とす計算である。
台帳には**型紙が無く**、`fabric/weight` は `UNKNOWN` のままである。この
状態で人台に巻きつけた絵を出せば、それは**生成された見た目**で、
「こう着られる」と読まれる。誰も知らないことを、立体の説得力で言うことに
なる。

代わりに**比べる**。服の周囲と体の周囲の差 = ゆとり。これは算術で、
作り手が実際に見る数字で、布の挙動を一切主張しない。

## 基準体は「着用者」ではない

人台は**寸法を比べる相手**であって、この服を着る人ではない。誰も
その人を観測していない。出力に「着用者」「着た姿」を名乗らない。

## サイズ展開

一つの寸法組から標準の振り分けで S/M/L を作るのは算術である。ただし
**振り分けで出た寸法は実測ではない** — `DERIVED` と同じ扱いで、
別の欄に立てる。基準になったサイズがどれかも残す。

## 測ること

- **VB1 基準体は観測ではない。** 体の寸法は台帳の観測欄に入らない。
  入れようとすれば断られる。
- **VB2 ゆとりは引き算。** 服の周囲 − 体の周囲。どちらかが未取得なら
  ゆとりも出ない(`UNKNOWN_NO_BASIS` と同じ扱い)。
- **VB3 負のゆとりを隠さない。** 服が体より小さければ負で出す。
  0 に丸めない — 入らない服は入らないと言う。
- **VB4 展開した寸法は実測ではない。** 派生として別の欄に立ち、
  基準サイズと振り分け量が残る。
- **VB5 展開は基準を書き換えない。** 何サイズ作っても、基準の実測は
  一つも変わらない。
- **VB6 決定的。** 同じ入力から同じ表。
- **VB7 着装を名乗らない。** 出力に「着た」「着装」「フィット」を
  断定する語が無い。
- **VB8 型紙が無いことを言う。** ゆとりの出力に、これが型紙による
  着装計算ではないと明記される。

反証: VB1 か VB7 が崩れたら出さない。観測していない体を観測にするか、
知らない着心地を語ることになる。
