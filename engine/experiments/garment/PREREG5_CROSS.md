# 事前登録 — 服飾台帳を立体十字に載せる (VC1〜VC6)

2026-08-22。ここまでの服飾台帳は**規律だけ**を立体十字から借りていて、
`garment.py` は標準ライブラリしか import していなかった。閉じた部位×側面の
表、三値を混ぜない、一般/実例、同点は棄権 — 考え方は同じでも、配置の本体は
呼んでいない。それは「立体十字で作った」とは言えない。

## どこに載るか

`ARMS = ("support+", "support-", "cause+", "cause-", "kind+", "kind-")` は
三つの双対そのもので、服飾の主張はそのまま乗る。

| 台帳 | core | facet | arm |
|---|---|---|---|
| 観測 | `garment:collar` | `shape:ノッチドラペル` | support+ |
| 割れた観測 | 同上 | 別の値 | support- (矛盾検出が拾う) |
| 推論 | 同上 | 値 | cause+ |
| 一般構造の申し立て | 同上 | `generic:教本p.88` | **kind+** |
| 実例の申し立て | 同上 | `specific:映画X` | **kind-** |

一般/実例は比喩ではなく、`ARMS` に実在するアームである。

## 測ること

- **VC1 二つの装置が同じものを割れていると言う。**
  台帳が `CONTESTED` とした側面と、十字の `contradictions()` が拾う
  側面が一致する。食い違うなら、どちらかが間違っている。

- **VC2 配置順は結論を変えない。** 入れる順を変えても、十字の
  矛盾集合と facet の集合は同じになる。**配置は情報を増やさない。**

- **VC3 一般と実例は別のアームに乗る。** `generic:` は kind+ 側、
  `specific:` は kind- 側に立ち、同じ側面に両方立てば割れている。

- **VC4 提案は確定の質量を増やさない。** 提案を十字に載せても、
  その側面の確定 facet の数は変わらない。載せるのは「言われた」
  という事実で、「そうである」ではない。

- **VC5 十字は台帳を書き換えない。** 十字を作り直しても台帳の
  entries は一つも変わらない。**十字は台帳の像であって台帳ではない。**

- **VC6 空の台帳から矛盾は出ない。** 何も置いていない十字に
  矛盾があると出るなら、検出器が形から作っている。

反証条件: VC1 か VC2 が崩れたら、十字に載せる意味がない(台帳の言い直しに
なっている)。VC5 が崩れたら、像が本体を汚している。
