## 一文で言うと

Verantyx は **Vera-α** を積んだ macOS の IDE です。Vera-α は決定論的な知識
エンジンで、保存された事実から答えるか、**なぜ答えられないかを型で**返すか
のどちらかしかしません。その経路に言語モデルは入りません。だから同じ問いに
は必ず同じ答えが返り、すべての答えは元の文まで遡れます。

```
> 避難所
🚫 UNKNOWN_NO_EVIDENCE
no_candidate_cross
単体 Vera-a は知らないことを推測しません。文書を投入するか、jgen 合議モードに切り替えてください。
```

これは空のストアに対する実際の応答です。同じ問いを LLM にすれば避難所につい
ての段落が返ります。段落を作るのが LLM の仕事だからです。Vera-α は何も保存
していないので、そう言います。

## 2つのエンジンを、ヘッダで切り替える

設定の奥ではなくチャットヘッダに置いています。両者は答えの**性格**が違い、
いまどちらを読んでいるかは、探しに行くものであってはならないからです。

| モード | 中身 | 向いている場面 |
|---|---|---|
| **jgen 合議** | LLM とエージェントの合議。JGEN でモデルを読み込む | 探索・下書き・未知の課題 |
| **単体 Vera-a** | 決定論のみ。保存された事実から型付きで答える。LLM を経由しない | 間違いが高くつく場面・監査・引用 |

拒否を LLM に言い直させることはしません。言い直した瞬間、その答えは再現も
引用もできなくなり、このモードの存在意義が消えるからです。

## Growth — システムが「知らないこと」

型付き未知の専用画面です。失敗のヒストグラム、繰り返す未知のバケットとその
分類(`growth_candidate` / `needs_more_facts`)、ギャップグラフ、5種の承認
待ち。ここにモデルの意見は一つもなく、すべて型付き失敗か人間の承認待ちの
件数です。

独立した画面にした理由は、この系の中核的な主張が「**何を知らないかを型と数
で把握している**」ことだからです。その数字が減っていくことが、この系での
「学習」の正直な意味であり、未知が1画面に見えなければ観測できません。

隔離された提案は勝手に効きません。あなたを迂回した成長は、信頼できる成長で
はないからです。

## 実測値

以下はすべて CI で再実行できる検査の結果です。主張ではなく結果です。

| | | 測り方 |
|---|---|---|
| 矛盾検出の精度 | **100%** | 仕込み罠(複合語・前置詞・従属節・条件節)で誤検出ゼロ |
| 検出率(正規形) | **100%** | 日英とも、学習に使っていない語彙で |
| 検出率(受動態・敬体) | **100%** | 「〜と報告された」「開館しております」 |
| 実文書での誤検出 | **0** | 2,633文書・211,989文 |
| 取り込み | **34MB を 14秒** | CPU のみ・シングルスレッド・GPU 不要 |
| 再現性 | **バイト単位で一致** | 同じコーパスを2回:出力もハッシュも同一 |
| 自動検査 | **83 + 8** | 83フォーク + 8評価スイート、CI 毎回 |

**限界を、見つけられる前にここに書きます**: 実コーパスでの「誤検出0」は
検出器が働く証拠では*ありません*。食い違いのない文章で誤爆しなくなった証拠
です。実在の公開文書に対する、人間が既知の食い違いを持つ測定はこれからで、
それが次に効く唯一の数字です。

## 文書に対して何をするか

PDF・Word・HTML・CSV・JSON・テキストをフォルダ単位で投入すると、決して混ぜ
ない4つに分けます。

- **確定** — 発言したすべての出典が一致
- **更新** — 同じ話が2度語られ、発表時刻で順序づく
- **係争** — 出典が食い違う。*どの出典がどちら側か*付き
- **未回答** — 誰も答えていない問いを、型付きの穴として名指し

これらを混ぜるのが要約であり、要約が判断に使えない理由です。読み手は、何が
合意されていて、何が争われていて、何を誰も確かめていないのかを区別できなく
なります。

**更新と係争を分けるのは時刻です。** 9時に通行止・15時に通行可能は一つの話
であり、これを対立として見せることが、情報担当者がこの板を信じなくなる瞬間
です。「更新」と呼ぶ基準は意図的に高くしています — 全側に日時があり、比較
可能で、厳密に順序づくときだけ。本物の対立を更新に格下げすると、この報告の
存在理由そのものを隠すからです。解釈できない日付は安全側に倒れ、係争を残す
ことはあっても偽の更新を作りません。

## 配置は説明でき、コード無しで調整できる

すべての配置判断には述べられる理由があるので、ボットがそれを述べます。

```
> 「本町の避難所は閉鎖されました」
ANSWER  この文の配置
コア: 避難所   ← は/が の前の句の最後の名詞(主辞後置)
ファセット: 本町、閉鎖
極: 開設／閉鎖 (−)  配置される — コアが主語なので
```

調整するのは**文法**であって、事実を手で動かすことではありません。ストアの
隣に `ja_grammar.json` を置けば起動時に読み込まれます。

```json
{ "antonym_pairs": [["点灯", "消灯"]],
  "predicates": {"点灯": "は点灯しています。"} }
```

検証器が不正な語彙を、全部の問題を名指しして拒否します — 2文字未満(開 は
開始・公開・展開の中にいる)、1語に両極、宙に浮いた参照。半分だけ読み込ま
れることはありません。

**配置を手で並べ替える道具は意図的にありません。** 手置きの事実は文から再導
出できず、この系の土台である再現性は、配置が「文 + 文法データ」の純粋な関数
であることを要求するからです。

## インストール

macOS 14+ (Apple Silicon) と Xcode が必要です。

```bash
git clone https://github.com/Ag3497120/Verantyx.git
cd Verantyx/cli/VerantyxIDE
xcodebuild -project Verantyx.xcodeproj -scheme Verantyx -configuration Release build
```

または [Releases](https://github.com/Ag3497120/Verantyx/releases/latest) から DMG を取得してください。

エンジンは自己完結バイナリとしてアプリに同梱されているので、実行に Python
の導入は不要です。エンジン自体に手を入れるなら
[Verantyx-Vera-alpha](https://github.com/Ag3497120/Verantyx-Vera-alpha) を
参照してください。基本インストールの第三者依存はゼロで、CI が「何もインス
トールする前に全モジュールを import する」ことでそれを証明しています。

## インストールせずに試す

[`site/`](site/) は1枚のサイトで、同じボットが**ページの中で**動きます —
サーバも API もモデルも使いません。設定の場所、独自 AI の作り方、文の配置を
聞けます。

```bash
cd site && python3 -m http.server 8899
```

ボットの語彙と規則はエンジンから書き出したもので、手写しではありません。移植
の等価性は Python 実装に対して15件で確認済みです。体験版の範囲はページに明記
しています:設定・モード・手順・**日本語の**配置。英語の文法分解はエンジン本体
に残しています。

## どこで本当に役に立つか

どこでも、ではありません。**間違えるコストが黙るコストより高く**、かつ
「なぜ答えが無いか」自体が次の行動になる場所に向いています。

- **災害情報** — 複数の機関、一つの事象、「実際どうなっているのか」という問い。
  オフラインで安価なノートPCで動きます。行列演算が一切ないので GPU は不要です
- **ビルド/CI 障害の切り分け** — 確認済み9パターン。障害の名前が対処法を指す
- **仕様と実装のずれ** — 自分の文書同士が食い違っている箇所
- **説明義務のある判断** — 「モデルがそう言った」ではなく、欠けている書類を
  名指しできる必要がある場面

向いていない場所も明記します:自由作文、要約、翻訳、雑談。文章を生成しません。
これは改善中の弱点ではなく、上記すべてを買うための取引です。

## 貢献

いま最も価値がある貢献は、**あなたが既に食い違いを把握しているコーパス**です。
仕込み正解に対する検出率は100%ですが、人間が実際の対立を印付けた実文書に対す
る検出率は一度も測っていません。その数字が、これが現場で信頼に足るかを決めます。

以下も歓迎します(価値の高い順):

- ドメイン語彙パック(生き残るために必要な複合語の罠つきで)
- 分野別の失敗パック(17パックのうち15は AI が種を入れたもので、専門家が確認
  済み事例を出すまで自己較正できないよう構造で禁じられています)
- 翻訳 — サイトと README は二言語です。他の言語も歓迎します
- 速度。エンジンは Python でストアを丸ごと書き直します。両方とも既知で、意図
  的に後回しです — 正確さが先で、故障モードは既に囲ってあるので(WAL・原子的
  置換)、最適化は危険ではなく安全な作業になっています
